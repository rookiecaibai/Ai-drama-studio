## B. 装上 Docker Desktop 后，请按顺序执行（预计 10 分钟）

```bash
cd backend

# 1) 起整套环境（首次会构建镜像，国内会从清华源拉 pip 包）
docker compose up --build

# 2) 预期输出：db 先 healthy，然后 api 日志出现
#    "[entrypoint] 执行数据库迁移..." 和 "Running upgrade ..."
#    最后 nginx 启动。整条链路在 http://localhost:8080

# 3) 验证接口（注意走的是 nginx 的 8080，不是 8000）
curl http://localhost:8080/api/v1/health
curl http://localhost:8080/docs

# 4) 完整业务流：注册 → 登录 → 建剧 → 加集 → 生成分镜
#    可以照抄 README 里的 curl 流程，把 8000 换成 8080

# 5) 验证容器健康状态（都应显示 healthy）
docker compose ps

# 6) 验证 MySQL 里真的建了表
docker compose exec db mysql -udrama -pdrama_password_change_me ai_drama -e "show tables;"
```

**验收标准**：第 3 步的 `/api/v1/health` 返回 200，且 `show tables` 能看到
`users / dramas / episodes / shots / generation_logs / alembic_version`。

## C. 上线到云服务器前，还要做的四件事

1. **换掉所有默认密钥**：`JWT_SECRET_KEY`（用 `python -c "import secrets; print(secrets.token_hex(32))"` 生成）、
   MySQL 密码、`MYSQL_ROOT_PASSWORD`。
2. **HTTPS**：nginx 配置里加 `server 443 ssl` 块，用 Let's Encrypt（certbot）签发证书。
3. **把 nginx 的 `server_name _` 换成你的域名。**
4. **打开配额**：`DAILY_GENERATION_LIMIT` 保持 20 或调低；`LLM_PROVIDER=openai_compat` + 真实 Key。
