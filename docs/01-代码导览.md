# 代码导览：按这个顺序读

> 读代码不要从 `main.py` 开始乱翻，按"一条请求的旅程"来读，理解成本最低。

## 一条请求的完整旅程

以 `POST /api/v1/episodes/1/generate` 为例：

```
HTTP 请求
  │
  ├─1─ Nginx（生产环境）：TLS 终止 + 反向代理 → api:8000
  │
  ├─2─ FastAPI 路由匹配：app/api/v1/episodes.py::generate_script
  │      └─ 请求体先被 Pydantic 校验：app/schemas/episode.py::GenerateRequest
  │         （不合法 → 自动返回 422，业务代码根本不会被执行）
  │
  ├─3─ 依赖注入：app/api/deps.py
  │      ├─ DbSession      → app/db/session.py::get_db()   （每请求一个 Session）
  │      └─ LlmProvider    → app/services/llm/factory.py::build_provider()
  │
  ├─4─ 取数据：app/db/models.py::Episode（找不到 → app/core/errors.py::NotFoundError → 404 JSON）
  │
  ├─5─ 业务逻辑：app/services/script_service.py::generate_episode_script
  │      ├─ 拼提示词（SYSTEM_PROMPT + 用户上下文）
  │      ├─ await provider.complete()          ← 真正花时间的地方
  │      ├─ _extract_json() 清洗模型输出（模型不一定听话）
  │      ├─ delete 旧 Shot + insert 新 Shot（幂等）
  │      └─ commit
  │
  ├─6─ 序列化：response_model=EpisodeDetail（含 shots）→ JSON
  │
  └─7─ 任何环节抛异常 → app/core/errors.py 的处理器 → 统一错误 JSON
```

## 建议的阅读顺序

| 顺序 | 文件 | 读它要搞懂什么 |
|---|---|---|
| 1 | `app/core/config.py` | 配置从哪来、为什么要单例 |
| 2 | `app/db/models.py` | 数据长什么样，三层模型为什么这样拆 |
| 3 | `app/schemas/*.py` | 对外契约与数据库模型为什么分开 |
| 4 | `app/db/session.py` | Engine / Session 的区别，`get_db` 为什么用 yield |
| 5 | `app/services/llm/base.py` → `mock.py` → `openai_compat.py` → `factory.py` | 依赖倒置长什么样 |

## 三个最值得记住的代码细节

**1. `get_db` 用 `yield`**
```python
def get_db() -> Iterator[Session]:
    with get_session_factory()() as session:
        yield session
```
`with` 保证请求结束（无论成功还是抛异常）都会关闭 Session。
写成普通函数返回 Session 而不管关闭，跑一段时间就会耗尽连接池——
这是新手最常见的线上事故之一。

**2. 服务层只认接口，不认具体模型**
```python
async def generate_episode_script(..., provider: LLMProvider, ...):
    raw = await provider.complete(system=..., user=...)
```
所以测试能塞一个 `BrokenProvider` 进去，验证"模型返回垃圾时返回 502"这条分支
（见 `tests/test_generation.py::test_llm_bad_output_returns_502`）。

**3. 幂等：重复点击不会产生脏数据**
```python
db.execute(delete(Shot).where(Shot.episode_id == episode.id))
# 再插入新镜头
```
如果只做 insert，用户点两次生成就会有 12 个镜头，而且每次点都翻倍。
"接口可重复调用而不产生副作用"就是幂等，是设计 API 时该主动考虑的事。
