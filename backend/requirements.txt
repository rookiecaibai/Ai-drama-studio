# --only-binary=:all:
#   Force prebuilt wheels only. Without it, pip may fall back to an sdist for
#   packages like cffi (pulled in by cryptography) and try to COMPILE C code
#   locally -- on a machine without a C toolchain that either fails after a long
#   time or burns CPU for many minutes. This single line turns a 10-minute hang
#   into a 40-second install. (This is a real bug we hit while building this repo.)
--only-binary=:all:

# Why: pip reads requirement files using the OS locale encoding unless a BOM or a
# PEP 263 coding cookie is present. On a Chinese Windows (cp936/GBK) locale, a
# UTF-8 file with non-ASCII comments crashes with UnicodeDecodeError.
# Comments must stay in English here; Chinese explanations live in docs/.

# is almost always caused by an upstream release. Pin, then upgrade explicitly.
