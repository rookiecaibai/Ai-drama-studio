# --only-binary=:all:
#   Force prebuilt wheels only, so pip never tries to COMPILE a package like cffi
#   (pulled in by cryptography) on a machine with no C toolchain. Wheels exist for
#   win_amd64 / manylinux, so this is a cheap safety net that keeps installs fast
#   and predictable.
#
#   NOTE: if `pip install -r requirements.txt` HANGS with no output, the culprit is
#   NOT this line -- it is a corrupted pip HTTP cache. Clear it with
#   `python -m pip cache purge`, or bypass with `--no-cache-dir`. See docs/02.
--only-binary=:all:

# Why: pip reads requirement files using the OS locale encoding unless a BOM or a
# PEP 263 coding cookie is present. On a Chinese Windows (cp936/GBK) locale, a
# UTF-8 file with non-ASCII comments crashes with UnicodeDecodeError.
# Comments must stay in English here; Chinese explanations live in docs/.
